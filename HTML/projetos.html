Small Platformer Game

Title: Platformer

This was one of my very first projects, it was made in Unity using C#, and it was when I was in 10th grade, so 15/16 years old at the time. The project itself fueled my passion for game development and programming in general, as I was able to see how code could bring something to life. The game itself was a simple platformer where the player had to navigate through randomly generated platforms that had a plugin built into them to make them generate under certain conditions. The game also had a scoring system that would be saved locally so the player could try to beat their own high score. Development time for this project was around 1 month and a half, as I was learning everything from scratch.
