Projects

In this section I'll tell you about some of the projects I've done during university as well as some other projects I've made for fun. Some of them might already be old while some are as recent as a few months old, however the experience and knowledge that came with them still remains.

Small Platformer Game

Title: Platformer

This was one of my very first projects, it was made in Unity using C#, and it was when I was in 10th grade, so 15/16 years old at the time. The project itself fueled my passion for game development and programming in general, as I was able to see how code could bring something to life. The game itself was a simple platformer where the player had to navigate through randomly generated platforms that had a plugin built into them to make them generate under certain conditions. The game also had a scoring system that would be saved locally so the player could try to beat their own high score. Development time for this project was around 1 month and a half, as I was learning everything from scratch.

LUDO in Node.js & Javascript

Title: LUDO - Computer Graphics

We had a dedicated subject to computer graphics where we learned the basics of 3D rendering, transformations, and other concepts. For the project of the subject, we had to create a simple 3D game, where we had weekly goals that were based on what we learned in class. My group decided to create a LUDO game, where we implemented the game logic, 3D models, and animations using WebGL and JavaScript. The project was a great learning experience of how to work with 3D graphics and game development. The development time for this project was the full semester.
