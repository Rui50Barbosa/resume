Projects

In this section I'll tell you about some of the projects I've done during university as well as some other projects I've made for fun. Some of them might already be old while some are as recent as a few months old, however the experience and knowledge that came with them still remains.

Small Platformer Game

Title: Platformer

This was one of my very first projects, it was made in Unity using C#, and it was when I was in 10th grade, so 15/16 years old at the time. This project is what fueled my passion for game development and programming in general, as I was able to see how code could bring something to life. The game itself was a simple platformer where the player had to navigate through randomly generated platforms that had a plugin built into them to make them generate under certain conditions. The game also had a scoring system that would be saved locally so the player could try to beat their own high score. Development time for this project was around 1 month and a half, as I was learning everything from scratch.

LUDO in Node.js & Javascript

Title: LUDO - Computer Graphics

We had a dedicated subject to computer graphics where we learned the basics of 3D rendering, transformations, and other concepts. For the project of the subject, we had to create a simple 3D game, where we had weekly goals that were based on what we learned in class. My group decided to create a LUDO game, where we implemented the game logic, 3D models, and animations using WebGL and JavaScript. The project was a great learning experience of how to work with 3D graphics and game development. The development time for this project was the full semester.

Final BSc Project

Title: Diabetic Foot Based on Temperature

In the last semester of the BSc we had a subject entirely dedicated to creating an app (where the theme was chosen in order from higher average grades to lower), and me and my partner chose to create an app that could help diabetic patients monitor their foot health based on temperature readings from their camera. The app would analyze the temperature, compare it to graphics and data from medical studies, and hopefully preemptively alert the user of any potential issues. We also had the opinion of a professional in the medicine field, which helped us a lot in the development of the app. C# was the biggest contributor, however the app also had login and registrationn features, where you could be a patient or a doctor (that could later check the pictures from the patients), so we also used SQL for the database and PHP for the backend. During this project, we also pitched our idea to the panel of professors as well as our colleagues, and we had to create a full report as well as a presentation. The final grade we obtained for this project was 16/20, and the development time was the entire final semester.
